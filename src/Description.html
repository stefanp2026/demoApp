Diese kurze Demo ist mit Visual Studio Code geschrieben.

Die Anwendung ist mit TypeScript und Vite gebaut.

Das Schachbrett wird per TypeScript im Browser generiert.

jQuery und jQuery UI sind für die Auswahl von DOM-Elementen und für Drag & Drop verwendet.

Die Logik ist mit Vitest getestet (pnpm test).

Die Bilder für die Schachfiguren sind aus einem Sprite-Image geladen.
